구구단 탐험대 - Cloudflare Pages 배포용

1. 이 폴더의 index.html, _headers 두 파일을 Cloudflare Pages에 업로드
2. 배포 주소를 Safari/Chrome에서 접속
3. 첫 화면에서 이름 등록
4. 이후 기록은 브라우저 localStorage에 저장되어 이어하기 가능

주의:
- 배경음은 저작권 음원이 아니라 오리지널 16-bit 항해/모험풍 루프입니다.
- iPhone/Safari 정책상 첫 '모험 시작/이어하기' 터치 후 음악이 재생됩니다.
- 같은 브라우저/기기에서 기록이 유지됩니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다.
