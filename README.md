# 구구단 포켓몬 궁전 v7

GitHub Pages / Cloudflare Pages 업로드용 웹앱.

## v7 추가 기능
- 연속 5 / 10 / 20문제 정답 시 주기적 칭찬 이벤트
- 오답 후 같은 문제를 다시 맞히면 '실수였어, 넌 할 수 있어' 계열 응원 팝업
- 매우 빠른 정답이 일정 조건에서 나오면 속도 칭찬
- 칭찬 시 밤하늘 불꽃놀이 피날레
- 응원 캐릭터(동물 마스코트) + 랜덤 메시지
- 웅장한 별도 칭찬 팡파르 효과음
- 칭찬 팝업은 약 1.8초 후 자동으로 사라지고 다음 문제
- 기존 20마리 포켓몬 수집, 타임어택, 나의 실력, 반응시간 기록 유지

## GitHub Pages
이 폴더 전체를 저장소 루트에 업로드한 뒤
Settings → Pages → Deploy from a branch → main / root 로 설정하면 됩니다.

## BGM
`caprice-for-lute.mp3`를 합법적으로 보유한 경우 저장소 루트에 추가하면 우선 재생합니다.
파일이 없으면 내장 WebAudio BGM이 재생됩니다.
