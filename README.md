# 구구단 포켓몬 궁전 v8

## BGM 변경
- 기존 전자음/칩튠 느낌의 내장 BGM 제거
- 오리지널 오케스트라풍 궁전 배경음으로 교체
- 현악 패드 느낌의 부드러운 화음
- 첼로/베이스 저음
- 하프처럼 잔잔한 분산화음
- 특정 구간에만 약한 금관 느낌의 상승
- 반복감과 고음 자극을 줄여 문제풀이 집중도 개선
- 일반 모드에서는 느리고 부드럽게
- 20마리 포획 후 TIME ATTACK에서는 같은 곡이 자연스럽게 1.5배속

`caprice-for-lute.mp3`를 저장소 루트에 넣은 경우 해당 파일이 우선 재생됩니다.
해당 파일이 없거나 브라우저에서 재생 실패 시 새 오케스트라 BGM이 자동 재생됩니다.

기존 기능:
- 2~9단 × 2~9
- 오답 시 같은 문제 즉시 재도전
- 단별 평균 반응속도 / 나의 실력
- 20문제마다 포켓몬 포획
- 20마리 후 타임어택
- 칭찬 팝업 / 불꽃놀이 / 응원 캐릭터
- 홈화면 앱 아이콘
